Operating pattern

Small tools first, platform habits second.

I test current tools early, including T3Code, Hermes, Codex, OpenCode, Aider, AnythingLLM, RAG stacks, and agent harnesses, but the test is always practical: can this help an engineer or domain expert move faster?

When a spreadsheet, inbox, review queue, finance process, or scientific handoff becomes the bottleneck, I build the smallest useful webapp or workflow. The pieces that prove useful get migrations, tests, observability, reproducible environments, CI, access control, documentation, and cleanup.
